# Helpmey homepage artwork

Place the exact approved `image_13.png` palace storefront artwork in this directory as `helpmey-palace-hero.jpg` (or update the `<img>` source in `index.html` to the committed filename). The homepage intentionally uses the original artwork as a single full-width hero image so its composition, branding, couple, shopping bags, department plaque and lighting are not reconstructed or altered.

The image itself was not present in the repository when this integration was performed; this note prevents the missing asset from being mistaken for a completed upload. Do not replace it with a generated approximation.
